# elkhoury_course05

Course 05 prework for the emlyon HIDS Python programming course: a Python project set up with uv, Git and GitHub. It includes the main data science packages (pandas, scikit-learn, matplotlib, streamlit) and a demo script that prints "Hello, world!".

## Installation

```bash
git clone https://github.com/emlyon-hids-python-2026/elkhoury_course05.git
cd elkhoury_course05
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
